# PROMVEXA AI

প্রাথমিক লোকাল প্রজেক্ট কাঠামো। এখনো কোনো অ্যাপ, রানটাইম সার্ভার বা ডিপ্লয়মেন্ট কনফিগার করা হয়নি।

| ডিরেক্টরি | নির্ধারিত ব্যবহার |
| --- | --- |
| `.github/` | ওয়ার্কফ্লো, ইস্যু ও পুল রিকোয়েস্ট টেমপ্লেট |
| `apps/` | ওয়েব, API, মোবাইল ও অ্যাডমিন অ্যাপ |
| `services/` | AI, প্রম্পট, অটোমেশন ও অন্যান্য স্বতন্ত্র সার্ভিস |
| `packages/` | শেয়ার্ড UI, টাইপ, ভ্যালিডেশন, পারমিশন ও API ক্লায়েন্ট |
| `database/` | মাইগ্রেশন, স্কিমা, সিড ও এক্সটেনশন |
| `infrastructure/` | ডিপ্লয়মেন্ট, নেটওয়ার্কিং ও মনিটরিং |
| `integrations/` | বাইরের প্ল্যাটফর্ম ও প্রোভাইডারের ইন্টিগ্রেশন |
| `scripts/` | ডেভেলপমেন্ট, ডিপ্লয়মেন্ট ও রক্ষণাবেক্ষণ স্ক্রিপ্ট |
| `tests/` | টেস্ট ও ফিক্সচার |

খালি ফোল্ডারে `.gitkeep` রাখা হয়েছে যাতে পরে Git-এ যোগ করলে সেগুলোও বজায় থাকে। `LICENSE` ফাইলটি আপাতত একটি প্লেসহোল্ডার।
